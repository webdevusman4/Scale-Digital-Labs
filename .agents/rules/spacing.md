# SPACING SCALE REFERENCE — ScaleDigitalLabs

Use these exact values when instructing any gap, padding, or margin change. Referencing a number from this scale (not an arbitrary one) keeps every future spacing tweak consistent with what's already on the site.

- **4px**   — hairline (icon-to-label spacing, tightest elements)
- **8px**   — tight (bullet icon to bullet text)
- **16px**  — compact (gap between related inline items, e.g. mini-stat dividers)
- **24px**  — standard (gap between a heading and its paragraph)
- **32px**  — comfortable (gap between paragraph and button/CTA)
- **48px**  — section-internal (navbar-to-hero-content gap — this is what's currently in use, and it's correct)
- **64px**  — section breathing room (gap between stacked cards in a grid)
- **80px**  — section-to-section (vertical padding between major page sections, e.g. Hero to Trust Bar)
- **100–120px** — section-to-section on desktop only, generous top/bottom padding for a page's very first section

## HOW TO INSTRUCT A CHANGE PRECISELY:
- **Bad:**  "add a bit more space above the headline"
- **Good:** "increase the hero's top padding-top from 48px to 64px"

- **Bad:**  "the cards feel too close together"
- **Good:** "increase the grid gap from 16px to 24px between the 6 overview cards"

## WHY THIS MATTERS:
Gaps that fall on this scale (or simple multiples of 8) read as "designed," while arbitrary values (like 37px or 52px) tend to look like an accident even if a person can't consciously say why. Keeping every future spacing request tied to one of these numbers keeps the whole site feeling intentional.
